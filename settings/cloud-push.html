这到底是什么功能？

简单说：它让 MAOMAO 可以把云端提醒送到你的设备，也为角色按设定时间主动联系你提供授权和调度入口。它不是一个新的聊天窗口。

推送通知

负责把云端发出的通知显示在这台设备上。打开它只代表允许接收通知，不会因此自动生成聊天内容，也不会替角色开启主动联系。

角色主动联系

给角色授权后，云端会根据全局开关、该角色的授权方式和作息判断是否可以主动联系。角色任务需要通过真实客户端与服务端联动后才可执行；目前未完成后台独立 AI 生成验收。允许时段之外、忙碌或休息时段，以及设为外出的角色，不会按普通主动联系时段发送。

设备配对

把另一台设备加入同一个云端账号。配对成功后，该设备也可以获得自己的推送订阅，并参与已授权的消息接收流程。

测试与诊断

「发送测试推送」只检查通知能否送到设备；「检查云端准备情况」用于查看配置和调度是否就绪，不会替角色发送聊天消息。

目前需要知道的限制：当前 QA 不承诺关闭应用后自动发消息：后端仍报告云端自主生成未就绪，需进一步整合与真机验收。服务端凭据与手机 API Key 完全分离；上下文共享默认关闭，关闭后会删除云端快照。推送订阅只负责把提醒送到设备，不决定是否生成消息。
