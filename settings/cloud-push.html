设备推送负责把云端通知送到这台设备；角色自主活动负责按角色授权和作息安排主动联系。两项设置彼此独立。

当前生成仍由已配对且前台运行的小手机调用本机 API 配置和聊天上下文完成。云端负责排队、授权检查与去重；应用关闭或处于后台时不会继续生成。

时区和允许主动联系的起止时间为必填；忙碌与休息时段可选。未保存有效作息的角色不会进入云端调度。

这到底是什么功能？

简单说：它让 MAOMAO 可以把云端提醒送到你的设备，也为角色按设定时间主动联系你提供授权和调度入口。它不是一个新的聊天窗口。

推送通知

负责把云端发出的通知显示在这台设备上。打开它只代表允许接收通知，不会因此自动生成聊天内容，也不会替角色开启主动联系。

角色主动联系

给角色授权后，系统才会参考全局开关、该角色的授权方式和作息，判断角色是否可以主动联系。允许时段之外、忙碌或休息时段，以及设为外出的角色，不应按普通主动联系时段调度。

设备配对

把另一台设备加入同一个云端账号。配对成功后，该设备也可以获得自己的推送订阅，并参与已授权的消息接收流程。

测试与诊断

「发送测试推送」只检查通知能否送到设备；「检查云端准备情况」用于查看配置和调度是否就绪，不会替角色发送聊天消息。

目前需要知道的限制：云端后台生成还要求单独开启上下文共享、配置服务端模型凭据，并完成调度与真机验收。服务端凭据与手机 API Key 完全分离；上下文共享默认关闭，关闭后会删除云端快照。
