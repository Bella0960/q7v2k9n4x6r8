04 / SECURITY

后台设置

账号授权、安全保护与审计规则

账号准入与邀请码强制规则

新账号创建后先进入待授权状态。必须使用绑定该永久账号 ID 的有效邀请码完成一次性核销，才能使用小手机。邮箱所有权验证未接通前，不开放邮箱目标发码路径。

账号生命周期强制规则

临时停用会撤销登录会话、设备凭据和关联有效邀请码。恢复时回到停用前保存的授权状态。永久撤销不可通过普通恢复操作复活，保留只读历史资料。

危险操作保护强制规则

停用、永久撤销、邀请码撤销、设备移除和会话撤销等操作必须先打开屏幕中央确认弹窗，明确显示对象与影响范围；只有再次点击确认按钮才会提交。

事务与异常恢复强制规则

账号状态、邀请码与对应审计事件必须在同一事务中提交。请求失败或发生并发冲突时，不得显示假成功；页面必须重新核对服务器状态后再提供操作入口。

审计记录与敏感信息只读保护

审计历史在普通管理界面只允许查询，不提供编辑或删除入口。记录保留操作人、目标账号、时间、状态变化及必要元数据；邀请码明文、密码摘要和会话令牌不得进入审计展示。

账号数据隔离强制规则

永久账号 ID 是账号数据分区依据，与真人好友 ID 和设备 ID 分离。所有私有 API 必须核对登录会话与页面账号上下文，不能依赖前端隐藏按钮代替服务器权限检查。

这些是系统强制安全规则，不提供普通开关。规则修改必须通过受控代码变更、回归测试和明确发布审批完成。
