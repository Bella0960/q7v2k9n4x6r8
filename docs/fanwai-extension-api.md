# MAOMAO 番外剧场 · 扩展接口 V1.1

原功能分支：`feat/fanwai-chat-episodes-20261115`（PR #296）。
联合验收分支：`integration/account-fanwai-stack-20261115`（基于既有账号 PR #290；**不可直接发布**）。

## 边界

- **复用当前聊天**：聊天页只通过现有 `chat-extras.js` 的「＋」面板加载 `chat-fanwai.js`；不改消息发送、聊天气泡主题或状态栏。
- **角色设定必读**：从当前角色 ID 对应的 `ai_custom_characters` 读取人设；用户设定来自原有 `myProfile`。
- **主线记忆默认不读**：进入模板预览后点只有「···」的隐藏入口才显示「不带记忆 / 参考角色记忆」；默认选择不带记忆。启用后只读当前角色人设中的 `memory` 字段，以及 `MemoryRecall.getMemories(roleId)` 返回的已确认／固定记忆（过滤其他角色和待确认记忆）；单个来源最多 1600 字符进入上下文。不会读取原始主聊天历史，也不会调用任何记忆写入、强化方法。
- **主线数据永不回写**：番外及其隐藏设定仅写入独立 `maomao-fanwai-v1` IndexedDB（故事记录与设定记录分别标记），并以账号 ID + 当前角色 ID 隔离。没有已认证账号上下文时仅保留当前页面会话的临时偏好，避免错账号落库。
- **只读上下文不是信任边界**：扩展 JS 与主应用运行在同一个页面，只有审查过的本地脚本才能注册扩展。扩展回调仅收到有限的、冻结的角色和用户资料快照，不会获得主线存储写入函数。任何扩展不应自己读写主线存储或上传隐私资料。
- **模型返回纯文本消息 JSON**，前端仅通过 `textContent` 构建聊天气泡，不执行生成的 HTML 或脚本。

## 稳定公共 API

加载 `chat-fanwai.js` 后使用 `window.MAOMAOFanwai`（`version: "1.1"`）：

```js
// ① 只添加新模板，不修改原有 6 张卡片或聊天页面。
const ok = window.MAOMAOFanwai.registerTemplate({
  id: 'rainyday',              // a-z 开头，之后允许小写、数字、-、_
  name: '雨天篇',
  subtitle: '雨后的闲聊',
  english: 'On a rainy day',
  mood: '日子慢慢地安静下来。',
  scenario: '雨停后，两人聊起生活中那些无关紧要却值得记住的小事。',
  target: 80,                 // 支持 40 / 80 / 100
  beats: ['开场线索', '推进剧情', '发生转折', '自然收束'] // 可选：四段故事节奏
});

// ② 注册可选的只读背景来源。默认不启用，生成前用户主动勾选才会调用 read。
window.MAOMAOFanwai.registerContextProvider({
  id: 'worldbook-snapshot',
  label: '世界书摘要',
  read: async ({ character, user }) => {
    // 仅返回当前角色的、安全且经用户选择的文字，不修改任何主线资料。
    return '';
  }
});

// ③ 订阅生命周期事件，用于日后增加番外收藏、作品目录或导出模块。
const unsubscribe = window.MAOMAOFanwai.on('episode:completed', ({ id, characterId }) => {
  // 仅通知完成的番外 ID、当前角色 ID；不附带私密故事正文、密钥或账号令牌。
});

// 离开插件页面前可 unsubscribe()。
```

可订阅的事件：`templates:changed`、`episode:created`、`episode:progress`、`episode:completed`、`episode:paused`、`episode:deleted`。监听器异常会被捕获，不中断番外生成。

另有 `listTemplates()`、`listContextProviders()`（均返回不暴露内部可变引用的简要配置）。`MAOMAOFanwaiCore` 提供纯逻辑方法 `episodePrompt`、`normalizeMessages`、`resolveContexts`，供 Node 回归使用。

## 扩建方式

新增模块放进自己单独的 JS 文件，由现有页面脚本加载后调用上述注册接口。**不必修改主线消息模型、番外生成函数或番外阅读页的 DOM 结构**。新的模板如果没有指定专门的封面样式，会使用通用的 Softcore CSS 模板；未来可以通过自己的作用域 CSS 定制对应 `.fw-card-<id>` 和 `.fw-scene-<id>`。

当前不允许任意网址注入 JS，不允许未经审查的外部模板执行代码。普通用户可通过「自定义番外」输入剧情文字，但其文字只会作为模型数据使用。

## 可玩性与费用控制

- 默认 6 种故事模板，每种通过四段式剧情节奏推进（开场、发展、转折、收束）；只对现有批量生成请求追加提示词，不额外购买一次大纲请求。第七个插件模板可通过 `beats: ['开场','推进','转折','收束']` 指定自己的四段结构。
- 阅读页的「···」里藏有「另一种走向」。至少生成 12 条消息后才显示；用户进入独立预览，可输入希望改变的情节，也可留空让模型发挥。
- 先预览、后确认：不点击「写另一种走向」就不发请求。确认后保留原篇前半段作为分岔起点，后续单独生成新故事，`originId`、`forkAt` 标明来源。原稿不会被删除或覆写，目录可同时读两条路线。
- 平行分支继续沿用**原故事**的角色、人设、已选择的只读记忆许可和目标篇幅，而不是读取其他角色或在跳转时擅自打开新的记忆。
- 阅读页取消了每个气泡上方重复的发言人标签：从左右位置区分双方，连续同一人消息视觉上更紧密。

## 回归

```bash
npm run test:chat:fanwai
npm run test:chat:contract
npm run build
```

重点人工验收：单聊 →「＋」→ 番外 → 选模板 → **先预览，不产生 API 请求** → 默认只看到封面/剧情/开始按钮 → 点小小的「···」才展开带/不带记忆及 40/80/100 条篇幅 → 开始生成 → 阅读页默认隐藏「返回目录/删除」 → 点「···」才展开 → 暂停、继续、关闭、最近番外。检查不影响主线聊天、角色记忆、主题商城、钱包和其他账号。上线仍需真实浏览器、Android 与 iPhone 验收；不绕过当前正式发布门禁。

### 续写与取消请求的并发保护

- **顺序提交**：番外消息和角色级隐藏偏好分别使用写入队列。快速切换记忆或篇幅时，后一次选择不会被前一次迟到的存储事务覆盖。
- **过期任务失效**：页面每次返回、关闭、切换模板、创建或打开故事都会更新页面版本；数据库写入或列表读取期间退出，旧的异步回调不能自行重新打开阅读页。未开始生成的空白草稿会清理。
- **暂停会尝试真正取消正在进行的网络请求**：公共 PhoneAPI.complete/completeJSON 新增向后兼容的可选 signal 参数。旧调用不传 signal，行为不变；番外暂停时通过 AbortController 尝试中止当前 fetch。**请求已发送后，服务商是否计费由服务商决定，客户端取消不能保证退款**。旧请求即使迟到也不会被写入新剧情。
- **完成事件失效检查**：在最后一次落盘后重新确认当前任务、打开页面和最新操作版本，防止用户退出后旧任务推送“已完成”或重绘界面。
- **回归压力测试**：模拟快速反复切换设置、保存期间退出、暂停后立即续写、迟到 AI 结果、最后一批落盘时退出、真实 AbortSignal 触发、超时与旧调用兼容。相应测试位于 tests/chat-fanwai-ui.test.mjs 和 tests/phone-api-abort.test.mjs。

## 本次安全与稳定性加固

1. **先落库，后生成**：创建新故事或平行分支时必须先收到 IndexedDB 事务完成确认。数据库写入失败时不发起收费模型请求。
2. **中途存储失败立即停止**：分批生成后必须成功持久化才进入下一批。发生存储配额不足、事务取消或写入错误时，停止剩余 API 调用，并明确提醒用户暂时不要关闭页面，以便保留内存里的文字。该次会话不再提供失效的继续生成操作。
3. **按账号、角色定向读取**：用 IDBKeyRange.bound 只读取“账号ID:角色ID:”前缀的番外主键，不再对整个共享 IndexedDB 执行无范围的 getAll()。无法执行范围查询时不扫描全库。
4. **二次确认删除**：阅读页「···」→ 删除 → 单独确认页。仅在 IndexedDB 删除事务成功完成后，才从目录撤下该篇；失败时原文仍保留。
5. **模型兼容性**：复用现有 PhoneAPI.completeJSON。根据用户配置的 maxTokens 将生成批量调整为 3/5/8/12 条；同批和邻近批次的重复消息不再重复保存。提示词随故事四幕推进。
6. **存档可达性**：默认仅展示最近 12 篇，页尾以小字「查看更多故事」每次展开 12 篇，旧番外不会因为超过 12 篇就无法访问。

**验证方式**：已添加针对账号角色范围隔离、保存失败不继续付费、中途存储失败、删除失败、低 Token 分批、超过 12 篇的归档、平行分支重载等自动化模拟回归。完整 Node/Vite、真实 Android/iPhone 与模型连接仍待验证，不能把模拟通过视为上线验收。

## PWA 账号隔离与预览部署门槛（2026-11-15）

- **账号级 HTML 不允许离线复用旧身份**：正式 Worker 在已登录页面返回 `Cache-Control: private, no-store`，PWA v206 不再把这种 HTML 放进 app-shell，也不从旧缓存提供此类页面；新版本激活时清理旧 `phone-app-` 缓存。防止切换账号后读到旧账号注入的 `mao-account-id`。
- **跳转后的登录页不得以旧路由缓存**：用户未登录时请求受保护的 `chat-detail.html` 可能被重定向到登录页。即使最终返回 HTTP 200，只要 `Response.redirected` 为真，安装预缓存、导航后台更新及静态资源更新都不能将它保存为原来的聊天页 URL。对应测试见 `tests/sw-private-account-navigation.test.mjs`。
- **账号接口禁止缓存**：`/api/`、`/account/`、`/internal/` 路径直接请求服务器，其他静态资源也尊重 no-store/private 响应。公共 HTML、CSS、JS 仍保留缓存优先与后台更新；受账号保护的 HTML 离线不可用（安全性优先，这是需要在真机验收时明确验证的取舍）。
- **新增测试**：`tests/sw-private-account-navigation.test.mjs` 覆盖私有页面跨账号不得重用、私有页面不入缓存、API GET 不读旧缓存、普通静态缓存仍可用；现有 `tests/sw-navigation-cache-lifecycle.test.mjs` 验证后台更新、缓存写入生命周期与离线公共页面回退。
- **实际构建阻碍已确认**：Cloudflare Builds 的账户额度接口返回 `has_reached_build_minutes_limit: true`，对应 PR 提交的构建记录状态为 `stopped / skipped`。其刷新时间是 `2026-11-30T23:59:59.999Z`。这不是 Vite 编译成功或失败的证据；禁止把旧预览 URL 当作最新提交的验收版本。
- **待完成**：完整的 Node/Vite 构建、真实模型、Android/Apple Safari 设备上可操作性及账号退出→登录场景。所有操作先在预览隔离环境进行，正式账号数据库不参与番外测试。

## 已知限制

- 本阶段的独立番外属于**本机存储**，不等于跨设备云端同步，也未合并到正式版。后续接云存储须另做服务器端身份校验与迁移验收。
- 「参考角色记忆」目前只读取当前角色记录的 `memory` 与已确认的 `MemoryRecall` 长期记忆，不读取所有世界书、原始聊天历史或其他账号数据。其他只读来源请通过 `registerContextProvider` 接入，并由用户明确选择启用。
- 隐藏的篇幅与记忆偏好会记住当前**账号 + 角色**的选择（同一浏览器的独立番外库），不意味着跨设备同步。


- 公开登录页断网回退只查当前 `CACHE_NAME` 对应的**公共 app-shell**，不能使用全域 `caches.match()` 搜索其他账号或旧业务模块的 CacheStorage。受保护聊天页面仍强制先经过 Worker 在线验证，不直接回退旧聊天 HTML。
- `tests/sw-navigation-cache-lifecycle.test.mjs` 原本面向全部导航的“缓存优先”假设已经改为**仅验证公开登录页**的网络优先 + 写盘生命周期；它与新增的账号私有导航测试共同覆盖离线安全边界。

## 本轮补强：身份标记与跨标签页存档一致性

- **认证身份判定严格失败关闭**：只要 HTML 存在 `meta[name="mao-account-id"]`，必须满足永久 ID 格式，并与已就绪的 `window.__MAO_ACCOUNT_SCOPE__.accountId` 完全一致；格式错误、作用域缺失、作用域未就绪或错账号，均在公开模板/记忆插件 API 之前停止执行。**没有账号标记**的纯静态本地预览仍只使用临时内存剧情，不读取认证数据。
- **归档以已提交的 IndexedDB 查询为准**：读取前等待本页写入队列完成；按账号及角色主键范围读取成功后，以数据库结果替换目录内存快照，尊重另一标签页已经完成的删除。范围读取失败、浏览器不支持安全范围查询时，不把失败当作“目录为空”，保留上次确认保存的快照并提示用户。
- **专项回归**：新增畸形账号标记不得读取 `ai_custom_characters` 的断言、其他标签页删除后不显示旧存档、数据库读取失败时保留旧存档并提示。已从 PR #299 当前源码执行四组 V8 合同与模拟 UI/PhoneAPI 回归 **45/45 通过**；**真实 Node/Vite/Chromium 仍 NOT RUN**，不得将这些模拟回归当作手机验收。
- **撤销方式**：本轮只改 `chat-fanwai.js` 及回归测试，不迁移/重建数据库、不修改主线聊天、正式账号或 Worker；需回滚时仅恢复本次小补丁提交。
