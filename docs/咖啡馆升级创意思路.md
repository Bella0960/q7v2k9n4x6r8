# 咖啡馆升级创意思路 · 黑白灰小剧场动画方案

> 目标：把咖啡馆从"一个经营表格"升级成"一间会呼吸的小剧场"。
> 保持黑白灰杂志风不变，加的是：简笔画、微动效、打烊仪式感。
> 全程纯 CSS + SVG，零外部依赖，沿用项目已有的 `stroke 黑线 / 无填充 / 圆角线帽` 简笔规范。

---

## 一、一句话定位

**白天是杂志排版的经营页，晚上是一盏灯亮着的小画。**
升级后，用户点开咖啡馆，第一眼不是文字，而是一间手绘的小店——灯亮着、有蒸汽、偶尔走过一个小人。点"开始营业"它忙起来，点"打烊"它像拉上卷帘一样慢慢暗下去。动画是配角，用来让"经营"这件事有仪式感，而不是炫技。

---

## 二、简笔画视觉规范（沿用现有、统一口径）

店里已经有 SVG 图标，这次把它们规范成一套：

- **线条**：`stroke:#222`，`stroke-width:1.2`（小图标）到 `1.8`（立面大图），`fill:none`。
- **线帽**：`stroke-linecap:round`、`stroke-linejoin:round`——所有转角和线头都是圆的，像手绘针管笔。
- **不填充**：除了偶尔的实心小黑块（门、窗暗部、月亮），一律线条。
- **灰度层次**：线用 `#222`，次要线 `#888`，背景用**纯白 `#ffffff`**（不要米黄/纸色），夜晚窗内光用 `#eee` 线。全程无彩色。
- **字体**：大标题还是 Georgia/宋体，和简笔画形成"印刷字 + 手画线"的对比。

---

## 三、Hero 立面：一间会动的小店

现在页面顶部是纯文字「把一家小店，慢慢经营好」。在文字旁边（或下方）加一个横向简笔画立面 SVG，大约占满屏宽、高 90px：

**画什么（从左到右）：**
- 一块竖招牌：画一个咖啡杯简笔，下面一条横线挂着
- 一个门：长方形 + 门把手小圆
- 一扇窗：窗里画一个小方桌 + 两个杯子
- 门口一级台阶
- 一盆小植物（三叶线条）
- 天上偶尔一朵简笔云

**会动的地方：**
- 门口上方一个小灯：营业时灯线发亮（用 `#222` 细线，做 2s 一次的微弱明暗呼吸 `cafe-bulb`）。
- 杯口三缕蒸汽：画三条曲线，用 `cafe-steam` 动画——缓缓上升、淡出、再长出来，循环。
- 云：每 12 秒从左飘到右（`cafe-cloud`），很慢，几乎注意不到。
- 搭档小人：在 partner 区头像旁边，一个极简火柴人站姿，营业时偶尔点头（`cafe-nod` 8s 一次）。

这些都用 `transform` 和 `opacity` 做，位移不超过 4px，速度慢（2~6s 一个循环），是"活着"而不是"闹腾"。

---

## 四、打烊动画（重点 · 分镜脚本）

现在点「开始营业·结算」是直接弹日报。改成两段仪式：**先演一段打烊小动画，再出日报**。时长约 2.2 秒，可点屏幕跳过。

分镜（顺序）：

1. **0.0s**：立面还是亮的，蒸汽还在升。
2. **0.3s**：门口小灯先灭（灯线 `#222` 淡出成 `#bbb`）。
3. **0.6s**：窗内的"灯光"（留白块）逐渐填成浅灰 `#e6e6e6`——像客人都走了。
4. **0.9s**：卷帘从门顶开始往下画：一条横线用 `stroke-dashoffset` 动画，从 0 拉到满高，像真的"哗啦"拉下（配合一个极轻的 `cafe-roll` 位移，带 2px 回弹）。
5. **1.3s**：天空里浮现一个简笔月亮（空心圆 + 两张短线做云），星星用 2~3 个极小的 `#222` 点，淡入。
6. **1.6s**：整个立面压暗一层——叠一个 `rgba(247,247,245,.0)` 到 `rgba(20,20,20,.18)` 的遮罩，纸色微微发灰，像夜里。
7. **2.0s**：右上角浮现一行小字 kicker：「CLOSED · 第 XX 天结束」，斜体。
8. **2.2s**：日报弹窗（现有 daily-report-modal）从底部升起，和现有 `cafe-pop` 衔接。

**打烊后状态：** 立面停在夜晚模式（卷帘关着、月亮在），下次进入"营业前"准备阶段时，卷帘再从下往上收起、月亮淡出、灯亮，形成一个完整的"开门—关门"循环。

## 五、数据反馈动效（让数字"活"起来）

现在数字是跳变的。加三处克制的反馈：

1. **现金滚动**：`st.cash` 变化时，用 JS 做一个 0.6s 的数字滚动（从旧值数到新值，`font-variant-numeric:tabular-nums` 保证数字不抖动），不是立刻跳。
2. **订单弹出**：营业模拟时，熟客卡片从列表顶部 `cafe-enter` 依次滑入（已有 stagger，复用即可），每来一位客人，门口小人旁边多一个小圆头简笔，停留 2 秒再走。
3. **成就盖章**：解锁成就时，不只是 `cafe-pop`，加一个"盖章"动作——一个圆形印章简笔从 1.2 倍缩到 1.0，带 0.15s 的轻微旋转，像在杂志上盖了个邮戳（`cafe-stamp`）。

## 六、常驻微动清单（氛围层）

| 元素 | 动画 | 周期 | 说明 |
|---|---|---|---|
| 招牌灯 | 明暗呼吸 | 2.4s | 营业时常亮微闪 |
| 咖啡蒸汽 | 上升淡出 | 3s 循环 | 三缕错峰 |
| 门口云 | 左→右漂移 | 14s | 几乎不可察觉 |
| 搭档小人 | 点头/眨眼 | 7s | 只动 2px |
| 菜单卡片悬浮 | hover 上浮 2px | — | 已有，保留 |
| 卷帘 | 上/下收放 | 0.9s | 打烊/开门用 |
| 月亮星星 | 淡入淡出 | 1s | 仅夜间状态 |

## 七、动画节奏原则（成熟游戏的克制感）

这是"像成熟软件"的关键，不是越多越好：

- **慢**：所有循环动画周期 ≥2.4s，位移 ≤4px。快动效只留给按钮按下（scale .975，已有）。
- **静多于动**：一屏里同时动的元素不超过 3 个。云、蒸汽、灯是背景，客人、盖章、打烊是前景事件。
- **有始有终**：每个动画都有明确的触发（开门、打烊、解锁、结算），不做无意义的自动闪烁。
- **可关闭**：保留已有的 `@media (prefers-reduced-motion: reduce)` 全量关闭。
- **不挡操作**：动画层 `pointer-events:none`，打烊动画期间可点屏幕跳过。

---

## 八、技术实现提示

- 全部新增动画写在 cafe.html 现有 `<style>` 里，和 `cafe-enter` / `cafe-pop` 并列，命名沿用 `cafe-` 前缀。
- 卷帘用 SVG `<rect>` + `stroke-dasharray`/`stroke-dashoffset` 做"画线"效果。
- 立面 SVG 内联在 hero，不引图片；灰度图一张都不加，保持纯线条。
- 数字滚动用一个小函数（约 15 行 JS），不改现有数据结构 `maomao_cafe_state_v1`。
- 打烊状态记在现有 state 里加一个 `phase: 'open' | 'closed'` 字段，随结算自然切换。

---

## 九、做完后的整体感受

打开咖啡馆：先是一间亮着灯、冒着蒸汽的手绘小店；你做决定、选菜单、补货；点营业，熟客一个个走进来；打烊时卷帘拉下、月亮升起、灯灭；最后日报像一张从收银台递出来的小纸片。
**它不再是一个经营面板，而是一页会翻篇的黑白漫画。**
