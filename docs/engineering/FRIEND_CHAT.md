# MAOMAO 真人好友文字聊天 MVP

## 当前范围

本阶段在现有「新的朋友」好友关系之上，增加两个已互相同意好友之间的纯文字聊天：

- 好友列表中的「聊天」入口打开独立聊天页面。
- 消息保存在 Cloudflare Worker 绑定的 Durable Object SQLite 中，方便双方跨设备读取。
- 聊天页可载入最近 50 条记录，并按游标向上读取更早消息。
- 聊天页在前台可见时每 4.5 秒轮询新消息；切到后台后暂停轮询。
- 客户端消息 ID 提供幂等保护，发送请求超时后使用相同 ID 重试不会重复插入。
- 每条消息最多 2000 个 Unicode 字符，只接受非空文字。

## 权限边界

- 每个读写接口都重新验证真人账号凭据。
- 只有好友关系表中仍然存在的双向好友关系才能读取或发送。
- 删除好友后，双方立即无法再通过消息 API 读取或发送。
- 客户端不能通过请求体写入图片 URL、附件或任意额外字段。
- 消息正文在页面中通过 `textContent` 渲染，不作为 HTML 执行。
- 服务端消息 ID 和游标由服务端生成；游标使用会话内严格递增的创建时间与消息 ID。

## 数据与隐私说明

- **当前聊天正文以普通文字形式保存在 MAOMAO 云端 SQLite 中，不是端到端加密。** 任何用户在试用前都应知晓这一点；不要把密码、验证码、支付信息或其他敏感内容发到当前 MVP。
- 消息不会发送给 AI 角色，也不会交给 AI 模型处理。
- 当前只存储文本、双方真人账号 ID、消息 ID 与创建时间；不存储图片、语音、位置或附件。
- 当前没有自动消息清理或用户主动删除单条云端消息的界面。删除好友会撤销聊天访问，但不会自动删除历史行；如果双方以后重新成为好友，旧历史仍可能重新可见。
- 当前没有后台推送、送达回执或已读回执。只有打开聊天页且页面处于前台时，才会轮询新消息。

## 接口

- `GET /api/friends/:friendId/messages`：读取最近一页消息。
- `GET /api/friends/:friendId/messages?after=<createdAt>.<messageId>`：读取游标之后的新消息。
- `GET /api/friends/:friendId/messages?before=<createdAt>.<messageId>`：载入更早消息。
- `POST /api/friends/:friendId/messages`：发送纯文字，请求体仅允许 `clientMessageId` 与 `body`。

所有接口都需要 `X-Maomao-Account` 认证，并再次验证双方好友关系。
