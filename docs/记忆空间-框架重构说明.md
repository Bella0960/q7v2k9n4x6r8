# 记忆空间 · 框架重构说明

日期：2026-10-31
范围：`worldbook/memory/memory.html`（仅框架：结构 / 样式 / 视图切换，业务函数与存储键未改）
备份：`worldbook/memory/memory.html.bak-framework`

## 一、为什么要重构

页面被三层改造脚本叠加过，累赘是叠加出来的：

| 层 | 位置 | 做了什么 |
|----|------|---------|
| L1 | 原始 HTML | 8 个区块平铺 |
| L2 | `memory-editorial-redesign` | 编辑风排版 |
| L3 | `memory-compact-navigation` | 把 5 个功能卡 `removeChild` 塞进全屏抽屉，加底部栏 + 右上「功能 +」 |
| L4 | `shared/js/phone/memory_space_v2.js` | 注入统计面板与搜索框，挂在抽屉 DOM 上 |

结果：同一功能出现 2–3 个入口，且 L3 用 `getTitle('AUTO SUMMARY')` 匹配中文标题失败，
「自动总结 / 记忆库 / 记忆工具」三个分组标题被留在页面上、内容被搬走，成为孤儿标题。

## 二、新框架

```
状态栏
大标题「记忆空间」+ 返回
────────────────────────
[ 记忆 | 整理 ]            ← 顶部两段主导航（吸顶）
────────────────────────
记忆页（看）                整理页（做）
  角色条                      自动总结（开关 + 触发阈值）
  概览统计 + 回看真实聊天      手动总结（分类 + 范围 + 2 按钮）
  最近一次真实对话            记忆工具（去重 / 合并）
  [ 时间流 | 记忆库 ]        高级参数（7 滑块，默认折叠）
    ├ 时间流：搜索 + 时间线 + 加入长期记忆
    └ 记忆库：确认 / 钉住 / 删除
```

- 主导航分「看」与「做」，消除「参数 / 自动 / 手册」三处分散
- 记忆的两种视图（原始聊天时间流 vs 提炼后的长期记忆）合并到一处，用二级切换，不再分散在两个抽屉
- 全屏抽屉改为页内常驻视图，保留 `mem-stream-drawer` 结构以便 v2 继续注入搜索框

## 三、功能对照（一个没删）

| 原功能 | 现位置 | 状态 |
|--------|--------|------|
| 角色选择 | 记忆页顶部 | 保留 |
| 今日碎片（v2 改写为最近一次真实对话） | 记忆页 | 保留 |
| 概览统计 4 项 + 回看真实聊天 | 记忆页（v2 注入，未改动） | 保留 |
| 时间流 + 搜索 + 加载更早 + 加入长期记忆 | 记忆页 · 时间流 | 保留 |
| 记忆库（确认/钉住/删除 + 状态/分类/重要性） | 记忆页 · 记忆库 | 保留 |
| 自动总结（开关 + 间隔） | 整理页 | 保留 |
| 手动总结（分类 chips + 范围 + 2 按钮 + 忙碌态） | 整理页 | 保留 |

被移除的只有**重复入口**，不是功能：

- 底部栏「记忆 / 总结 / 管理」→ 由主 Tab 承担
- 右上角「功能 +」→ 由「整理」Tab 承担
- 两个全屏抽屉 → 改为页内视图
- 3 个孤儿标题 → 内容已归位，标题不再孤立

## 四、顺带修掉的问题

1. **「调节 +」点了不展开**：CSS 写 `#summarySettingsCard.is-open`，JS 却加 `settings-show`，现已统一为 `is-open`。
2. **孤儿标题**：`getTitle('AUTO SUMMARY')` 匹配中文标题失败，导致三个标题留在页面且内容被搬走，现已归零。
3. **同一功能多入口**：记忆内容原本可从预览、底部栏、概览 CTA 三处打开，现只有一条路径。
