# MAOMAO · 轻薄杂志式交互设计参考

更新：2026-11-12

## 来源与适用范围

用户提供的四段私人参考视频与静态参考图（2026-11-12 重新核对）用于研究排版、交互逻辑和转场手感。原始视频、用户私人内容、第三方图片、字体与聊天文案不拷入仓库，也不作为可发布资源。**这不是规定每个页面都做成同一套主题**，而是供今后聊天、论坛、日记、足迹和各类应用结构设计参考。

## 用户明确关注的设计原则

1. **视觉要简单，关系要精密**：头像与姓名相邻，名字—时间—状态—正文按强弱层级排列；减少大块装饰和无意义隔线，保留有节奏的空白。
2. **轻薄而不空洞**：深浅灰对比准确，常规说明文字约 9–11px、列表名字约 12–13px、独立大标题约 18–23px；以手机可读性为前提，不将字号一味减小。
3. **内容拥有自己的位置**：顶部身份/封面、轻量进度线、聊天列表、展开侧栏、独立输入区各自有明确的层次；单页元素不靠绝对定位相互遮挡。
4. **互动让页面活起来**：轻触反馈 150–240ms；推拉/滑入主转场 280–460ms，使用温和 ease-out；导航、侧栏、状态变化在动线中有连续性；反馈随动作发生，绝不空转。
5. **微交互必须是真的**：不能做只改变播放图标但不播放的音乐按钮；不可建立第二个发送函数/聊天数据库；路由、联系人、引用、长按与系统消息必须复用 MAOMAO 原有链路。
6. **深浅模式各自成立**：色彩、透明度、文字对比和面板层级成体系切换；检查旧页面末尾 `!important` 样式对选中主题的污染。
7. **交互可退可还原**：返回后滚动位置/焦点合理恢复；侧栏打开时锁住背景，按 Escape、点击遮罩或左滑可关闭；浏览器不支持动画时有静态回退；尊重 `prefers-reduced-motion`。
8. **严守视觉边界**：延续黑白灰、衬线标题搭配无衬线正文、极细线条图标，不在页面上放 Mao./MAO 装饰字样，不添加 Emoji 图标，禁止紫色渐变与未授权素材。

## 可复用交互语法

- 列表行：轻压微位移、悬停/按下产生极浅背景，字重和时间信息稳定。
- 侧栏：横向推拉而非突兀弹出；背景轻微位移、遮罩轻淡模糊；导航真实跳转；可从屏幕左边缘手势打开，但不得抢占垂直滚动。
- 聊天详情：消息按角色轻巧对齐、引用视觉次级、时间元数据更细；输入栏固定在安全区域上方，发送按钮由原生 form 状态控制。
- 主题切换：切换只影响展示及单独外观偏好，不覆盖聊天消息、角色资料、头像、封面和用户自定义气泡。
- 时间线/日志：日期与事件以细竖线连接，条目展开有反馈；不要一次呈现过量标签或卡片。
- 动效时序：小按钮 180ms 左右；展开 280ms 左右；页面推拉约 360ms；仅供调优的初始值，最终以真机流畅度验证。

### 我们独立新增的设计方案（不声称来自视频原作）

- “我的主页”本身是 `chat/moments/my-moments.html`，不同于 `profile/profile.html` 的“我的”入口页；两个页面不能混为一谈
- 利用我的主页**已有动态**中的图片，生成可滑动、可点击定位到原帖的缩略图带；不复制图片到新数据库
- 主页提供“全部 / 照片 / 文字”的轻筛选，筛选只变更可见性，动态删除、评论、点赞、统计仍由原页处理
- 封面快捷操作调用原 `coverInput` 上传流程，沿用 `my_home_cover_v1`，严格与 `myProfile.cover`、聊天背景、动态封面分开
- 标题不拼贴无意义英文 LOGO；`MY SPACE` 只是小字号功能导航标识，而不是产品 Logo 或用户署名
- 深浅外观共用 `maomao_atmosphere_tone_v1`；图片适配、替代文本、键盘焦点、低动态偏好与原主题还原全部列入验收

### 设计验收标准

1. **真实数据**：图库与动态数量一致；没有照片时不显示空图库；新增/删除动态后图库和筛选同步更新。
2. **触感**：42px 左右可触控入口、19px 左右等线宽 SVG、指尖按压反馈 180–240ms；动画既不抢占垂直滚动，也不藏住重要操作。
3. **对齐**：头像、名字、签名共享中轴；左右功能入口各有真实点击区；320/375/390/430px 均不出现横向整体溢出。
4. **视觉独立**：更换我的主页壁纸不改变“我的”、聊天背景和朋友圈封面；切换旧主题时过滤器和额外控件完全退出。
5. **可追踪证据**：静态样式断言/JS DOM 模拟通过不等于完整浏览器验收；正式发布前必须检查实际路由、上传、评论、点赞、长帖、键盘和 PWA 更新。
