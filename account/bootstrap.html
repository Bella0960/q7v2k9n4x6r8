ONE-TIME INITIALIZATION

创作者初始化

首次部署时创建唯一超级管理员。初始化成功后，此入口永久关闭。

此操作仅适用于 MAO 创作者本人。初始化前，需在 Cloudflare Worker Secrets 中配置 MAO_SUPER_ADMIN_BOOTSTRAP_SECRET（至少 32 位），并确认 DEVICE_SECRET_PEPPER（至少 32 位）已配置。此页面不会显示或保存服务器密钥，切勿将密钥发给其他人。
正在确认服务器初始化状态…
还差一步，就可以创建管理员 001

在 Cloudflare 控制台找到 Worker mao 的当前账号测试 Preview，添加两项类型为 Secret 的变量：

DEVICE_SECRET_PEPPER — 独立随机值，至少 32 个字符。

MAO_SUPER_ADMIN_BOOTSTRAP_SECRET — 另一组独立随机值，至少 32 个字符；创建管理员时要填这一组。

不要把密钥写进 GitHub、公开聊天或截图里，也不要改正式 Production 的密钥。当前 Preview 已经创建，Cloudflare 的 Previews Base 设置只会影响以后新建的 Preview。

当前测试 Preview 的准确配置命令

在已登录 Cloudflare 的 Wrangler 环境中依次运行，下列命令会交互式询问密钥值：

npx wrangler preview secret put DEVICE_SECRET_PEPPER --worker-name mao --name integration/account-001-current-main-20261111

npx wrangler preview secret put MAO_SUPER_ADMIN_BOOTSTRAP_SECRET --worker-name mao --name integration/account-001-current-main-20261111

输入值请使用下方本机生成的不同密钥。完成后点击上方「重新检查」，不要在公开终端命令里直接写密钥值。

生成后分别复制到 Cloudflare 的对应 Secret。只保存在当前页面内存，关闭或刷新就会消失；请勿公开。
